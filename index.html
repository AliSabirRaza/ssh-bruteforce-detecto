How to read it


    

  • Each line is one login event from the server's log. Only failed and successful password lines are counted.
    • 

  • A burst is the most failures from one IP inside the time window.
    • 

  • An IP is FLAGGED when its burst reaches the threshold.
    • 

  • Compromise is YES when a flagged IP logged in successfully after its last failure.
    • 



To compare with the Python version, run py Python11.py then py Python12.py generated.log. The final results should match.
